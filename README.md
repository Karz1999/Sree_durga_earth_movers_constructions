# Sree Durga Earth Movers & Constructions

Static website scaffold for the company portfolio site.

## Files

- `index.html` — main homepage with navigation, hero, services, gallery, contact, and enquiry modal.
- `assets/css/styles.css` — responsive styling and theme.
- `assets/js/main.js` — navigation, modal, form submit, gallery lightbox, and scroll reveal.
- `assets/images/` — copied image assets from the existing `resource/` folder.

## Next steps

1. Replace the Formspree form action in `index.html` with a valid endpoint or your own email handling service.
2. Update WhatsApp and Instagram URLs with the real phone number and handle.
3. Verify image names and replace placeholder gallery images as needed.
4. Deploy as a static site on GitHub Pages or Vercel.

## Development

Open `index.html` in a browser to preview the static site.

For GitHub Pages deploy, publish the repository branch and configure the site source to `main` or `gh-pages`.
